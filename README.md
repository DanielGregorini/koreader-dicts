# koreader-dicts

Bilingual StarDict dictionaries for [KOReader](https://koreader.rocks/), built
from open lexical sources.

Each dictionary is generated by joining two wordnets through the Princeton
WordNet synset identifiers they share, then merging Wiktionary on top for
slang, idiom and inflected forms. The inflected forms are indexed, so a word
can be looked up as it appears on the page rather than in its dictionary form.

Not affiliated with the KOReader project.

## Downloading a dictionary

Download the `.zip` for the pair you want from
[Releases](https://github.com/DanielGregorini/koreader-dicts/releases/latest),
or straight from the command line:

```bash
curl -LO https://github.com/DanielGregorini/koreader-dicts/releases/latest/download/en-pt.zip
```

Unzip it and copy the **folder** — not its contents — into the dictionary
directory on your device:

| device | directory |
|---|---|
| Kindle | `koreader/data/dict` |
| Kobo | `.adds/koreader/data/dict/` |
| Android | `/sdcard/koreader/data/dict` |
| PocketBook | `applications/koreader/data/dict` |
| Cervantes | `/mnt/private/koreader/data/dict` |
| Linux | `$HOME/.config/koreader/data/dict` |
| macOS | `$HOME/Library/Application Support/koreader/data/dict` |

You should end up with `koreader/data/dict/en-pt/en-pt.ifo`. Restart KOReader
and the dictionary appears in the dictionary list. Long-press a dictionary name
in a lookup popup to reorder them.

## Building from source

```bash
pip install -e .
kdicts fetch pwn30 omw-pt wikt-pt wikt-en-pt
kdicts build en-pt --verify-sample 5000
kdicts catalog
```

The output lands in `dictionaries/en-pt/`. `docs/build-process.md` explains what
each step does; `docs/adding-a-pair.md` covers adding a new language pair.
